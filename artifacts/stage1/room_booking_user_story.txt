Room Booking Feature

As a guest,
I want to reserve an available room from the Shady Meadows B&B website,
so that my booking is confirmed and can be verified through the booking API.

Acceptance Criteria:
- User can open the Shady Meadows home page.
- User can view available room cards.
- User can open a reservation page for a room.
- User can submit valid guest details for future check-in and checkout dates.
- The UI shows Booking Confirmed after a successful reservation.
- The created booking can be fetched from the booking API by booking id.
- API booking details match the submitted guest name and booking dates.

Negative Criteria:
- Booking tests should not assert an exact booking id.
- Admin-only flows should not be generated unless admin credentials are provided.
